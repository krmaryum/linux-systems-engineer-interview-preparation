# Linux Systems Engineer I & II Interview Preparation

Learn it. Practice it. Troubleshoot it. Explain it.

A structured, hands-on learning repository for Linux Systems Engineer I and Linux Systems Engineer II roles. The project focuses on Red Hat Enterprise Linux administration, production troubleshooting, Bash automation, AWS, security, monitoring, change management, root cause analysis, and technical interview preparation.

## Learning Layers

1. Shared Linux Foundation — Modules 01–10
2. Linux Systems Engineer I — Modules 11–22
3. Linux Systems Engineer II — Modules 23–36
4. Job Readiness — Modules 37–40
